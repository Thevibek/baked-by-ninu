# Baked by Ninu - Cookie Business Website

A modern, responsive website for "Baked by Ninu" cookie business, featuring an elegant design with pastel colors and a user-friendly interface.

## Features

- Responsive design optimized for all device sizes
- Modern Bootstrap 5 framework implementation
- Elegant pastel color scheme
- Interactive elements with smooth animations
- Mobile-friendly navigation
- Product showcase gallery
- Testimonial carousel
- Contact form and newsletter signup
- Social media integration

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome Icons
- Google Fonts

## Setup Instructions

1. Clone or download this repository to your local machine
2. Open the `index.html` file in your web browser to view the website
3. For development, you can use a local server:
   - If you have Python installed, run:
     ```
     # Python 3.x
     python -m http.server
     ```
   - If you have Node.js installed, you can use:
     ```
     # Install http-server globally (if not already installed)
     npm install -g http-server
     
     # Run the server
     http-server
     ```

## Customization

- Replace placeholder images in the `images` folder with actual cookie photos
- Update contact information in the footer section
- Modify cookie product listings in the products section
- Adjust color palette in the CSS variables (in `styles.css`)
